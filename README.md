# 📚 webLaPalacio

Aplicación web full-stack desarrollada con arquitectura MERN para la
gestión y visualización de contenidos de librería. Permite autenticación
de usuarios, consumo de API REST y administración de datos en MongoDB.

## 🧠 Descripción

webLaPalacio es una aplicación MERN construida como proyecto full-stack
para practicar:

- arquitectura cliente/servidor
- autenticación con JWT
- validación de datos
- consumo de API desde React
- persistencia en MongoDB

El proyecto simula un entorno real de gestión de contenidos para una
librería independiente.

## ⚙️ Instalación local

### 1. Clonar repositorio

```bash
git clone https://github.com/k-hroma/webLaPalacio.git
cd webLaPalacio
```

---

### 2. Backend

```bash
cd backend
npm install
npm run dev
```

Crear archivo `.env`:

```env
MONGO_URI=tu_uri
JWT_SECRET=tu_secret
PORT=4000
```

---

### 3. Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🧪 Variables de entorno

Backend requiere:
